# Dart Programs 🎯

A comprehensive collection of Dart programming examples and exercises, following the **Rivaan Ranawat Flutter 20-hour tutorial series**. This repository covers fundamental Dart concepts from basic syntax to advanced programming patterns.

## 📚 Learning Path

### Beginner Codes (`beginner-codes/`)
Core Dart fundamentals covering:

#### **first-program.dart**
- Variables and data types (int, double, String, bool)
- Variable declaration: `var`, `final`, `const`
- String interpolation and manipulation
- Null safety and nullable variables (`?` operator)
- Control flow: if-else statements
- Ternary operators
- Switch statements with guards (Dart 3.10+)

#### **functions.dart**
- Function declaration and return types
- Functions with parameters
- Functions with no return value (void)
- Multiple return values using records/tuples
- Nullable return types (`String?`)
- Function destructuring

#### **loops.dart**
- For loops (traditional and range-based)
- String operations and indexing
- While loops (entry-controlled)
- Do-while loops (exit-controlled)
- Loop control: `break` and `continue`

## 🚀 Getting Started

### Prerequisites
- [Dart SDK](https://dart.dev/get-dart) installed
- A text editor or IDE (VS Code, Android Studio, or IntelliJ IDEA recommended)

### Running Programs

Run any Dart program using:
```bash
dart run <filename>.dart
```

Example:
```bash
dart run beginner-codes/first-program.dart
```
